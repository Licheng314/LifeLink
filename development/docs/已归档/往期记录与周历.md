# 往期记录与全局周历

状态：2026-08-29 已完成代码、自动化与本机 WebUI 验收。

## 已实现

- 左侧标题区、分割线上方显示周日到周六的业务日周历，今日以圆点标记，所选日期以框选标记。
- 未来日期和无数据历史日期不可选；历史态只在 Life Link 标题旁显示“历史数据”，浏览非当前周时月份旁提供“返回”。
- 时间线、应用使用、位置和健康读取所选业务日；心愿和当前管理状态保持现状。
- 中央提供 `GET /v1/calendar-days`，按共享跨日设置返回日期可用性与长期库逻辑记录量；用量、位置、健康、时间线和其他模块互斥计数。
- 当前日的时间线继续每 30 秒读取共享缓存，内容未变化时 WebUI 和小窗均不重绘；历史日不自动刷新。
