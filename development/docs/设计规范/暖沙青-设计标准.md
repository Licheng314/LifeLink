# Life Link 暖沙青（Warm Sand Cyan）设计标准

> 设计稿参考：`https://ardot.tencent.com/file/716645206965151`（应用使用页视觉稿）
>
> 生效日期：2026-08-22
>
> 适用范围：`pc-dashboard` Web UI 全部页面

## 设计气质

夕阳沙色底上，青绿是那颗被凝望的星。暖沙底 `#F5F1EA` 是黄昏环境，青绿 `#35D4AC` 是那颗五角形编织星，橘黄 `#FBBF24` 是夕阳光的边缘。整体克制、温暖、不刺眼，适合 AI 伴侣产品的个人仪表盘。

本轮设计不仅定义视觉皮肤，也定义两个现役信息结构：首页“业务日时间轴”负责在一个完整跨日窗口中提供事件分布总览，下方事件卡片负责阅读正文；位置页“停留地图”负责把定位观察点、轨迹方向、起终点和停留时长放进空间关系中。后续改版不得把它们降级成纯装饰图，也不得用步数伪造地图轨迹。

| Token | 色值 | 用途 |

## 8. 设计原则速查

- **不要用纯白**：卡片用 `#FFFDF9`，比纯白多一层暖意。
- **青绿是点睛，不是铺满**：主色用在按钮、选中态、进度条、链接。大面积用暖沙底。
- **橘黄是温暖的第二声**：网站排行、状态图标、强调数字用暖黄，不要和青绿抢主位。
- **文字用暖灰黑**：`#3E3A36` 和 `#9B9186`，不是冷灰 `#6B7280`。
- **描边要有温度**：`#E8DED0` 是暖色描边，不是冷灰蓝。
- **圆角放大**：18px 卡片圆角 + 10px 导航圆角，比原来 12px 更柔和。
