# PC 番茄钟阶段收尾

更新时间：2026-10-11

## 任务边界

- 用户目标：PC 用时小窗增加 25 分钟工作 / 5 分钟休息、工作目标、收起气泡及完成事件，并对齐久坐与时间区间布局。
- 风险：中型；当前代理直接执行。允许修改 PC 计时/绘图模块、本地事件幂等入口、中央事件投影、相关契约说明、测试和文档。
- 明确不做：Android 修改、用户运行数据改写、图片上传、远程推送或部署、APK/EXE 打包、分支/工作树/截图清理。
- 验收标准：计时转换与暂停恢复正确；切换不清零久坐；事件稳定重试不重复；窗口布局和收起绘图有专项测试；提交仅包含本阶段文件。
- 事实权威：具体 UI 与启动规则见 [PC README](../../../pc-dashboard/README.md#番茄钟与久坐提醒)，事件语义见 [中央交付契约](../../contracts/central-delivery-v1.md)。本单不再保留被后续设计取代的尺寸和布局。

## 最终交付

- 番茄钟默认待开始；填写目标后运行 25/5 流程，下一轮预填上轮目标。未完成会话重启后暂停恢复，已完成会话只保留目标及待上传事件，不恢复结算页。
- 久坐提醒、番茄钟、「无」为独立页签；前两者分别显示计时卡和时间区间卡，「无」隐藏计时卡，回收高度给事件列表。切走暂停并保留计时，久坐返回继续、番茄返回手动继续。
- 展开高度 512；全部面板统一小圆角，只有标题栏置顶。收起模式同心圆、密排操作按钮、固定展开锚点；久坐从 12 点逆时针正计时，番茄倒计时与单行目标。
- 时间区间保留全天总览及原进度条。无当前生效区间时显示白色本地时间，展开到秒、收起到分钟；区间倒计时不足一小时在收起模式使用 `MM:SS`。
- 抗锯齿和逐像素透明使用 Windows 原生接口，不新增 Pillow 或其他 PC 运行依赖。中央读取频率不因每秒本地刷新而提高。
- 普通 AFK 不暂停番茄；锁屏/睡眠暂停。番茄独立于每日时间区间，区间边界不强行中断它。

## 数据与契约

- 状态和待提交事件保存到用户目录 `client/data/pomodoro.json`，不落源码目录。
- 工作计时结束产生既有 `custom.event / pomodoro.completed`，稳定 UUID 和发生时间经现有 outbox 上传；休息结束不再生成一次事件，计时完成不证明目标达成。
- 本地服务支持稳定事件幂等重试并拒绝 ID 内容冲突；桌面提交前核对能力，旧服务暂缓提交并保留待上传事件。
- 中央只新增设备类普通事件投影与目标/计时证据，不新增表、数据迁移、权限或鉴权方式。
