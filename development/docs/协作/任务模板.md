# Life Link 代理任务模板

复制本模板形成一次独立任务单。未填写的项目不得由执行代理自行扩大解释。

```yaml
任务名称:
用户目标:
风险等级: 小型 / 中型 / 大型 / 机械

执行配置:
  建议模型: gpt-5.6-terra
  推理强度: low / medium
  继承上下文: none

必须阅读:
  - development/docs/README.md
  - development/docs/项目总控.md
  - 对应专项规范、契约和模块 README

允许修改:
  -

明确不做:
  -

数据与契约影响:
  权威数据来源:
  是否修改共享契约: 否
  是否迁移或删除数据: 否
  是否影响认证或同步: 否

验收标准:
  -

测试分工:
  执行代理运行:
    - 专项测试
  总控验收运行:
    - 必要的全量回归或关键反例

交付要求:
  - 修改文件
  - 实际行为变化
  - 测试数量与结果
  - 未完成风险
  - 是否需要真实设备验证
```

开始执行前，用一句话向用户公开调度方案，例如：

> 本次为中型任务，使用 Terra-medium、无历史上下文；执行代理跑专项测试，总控负责最终回归。
