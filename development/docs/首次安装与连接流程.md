# Life Link 首次安装与连接流程

> 状态：现役设计基线。用于校对首次安装脚本、用户指南和后续发布包，不作为普通用户操作说明。

## 1. 文档边界

- `development/` 属于源码仓库的一部分，供开发者和开发 AI 理解、测试、校对项目；这里不得存放用户隐私、真实 Token 或私有数据。
- 普通用户发布包不包含 `development/`、测试、任务单和构建中间产物，只包含运行文件、必要资源和用户指南。
- 直接同步源码仓库的用户必然能看到开发文档。根目录用户指南应让普通用户不必进入 `development/`。

## 2. 发布前

1. 仓库不包含真实用户数据、私密 Token、运行日志和本机配置。
2. Android 安装包与当前服务端契约版本匹配，不以“永远最新”替代兼容性确认。
3. 首次启动所需的 Python、启动器构建依赖与失败提示已验证。
4. 发布物包含根目录《快速开始》，普通发布包排除开发资料。

## 3. 中央服务首次启动

用户运行 `central-server/start_server.bat`。

1. 检查 Python 3.13 或 3.14。中央核心和 Windows 托盘均不再依赖 Tkinter；已有合格版本直接复用，缺失时征得同意后安装，无法自动安装时给出明确处理方式。
2. 检查启动器。缺失时准备隔离的构建环境并生成 `central-server/LifeLink Central Service.exe`；启动器生成或确认存在后，立即登记为当前 Windows 用户登录后自动启动。若用户或 Windows 已明确阻止，则保留该选择并给出提示。
3. 检查中央数据端口：默认尝试 `8091`；首次安装遇到占用时选择后续可用端口；已有安装遇到占用时显示原端口和候选端口，得到确认后才切换。PC 数据展示 WebUI 固定使用 `8090`，不是中央数据 API。
4. 启动中央核心，同时验证数据 API `/v1/health` 和固定管理入口 `http://127.0.0.1:8092/api/status`。8092 被其他程序占用时管理入口初始化失败并明确报告；数据 API 不伪装成管理入口。
5. 打开只限服务器本机的中央管理 WebUI。页面显示真实中央数据转发目标，并允许配置公网服务器/域名、Tailscale 或 HTTPS 内网穿透；三者只保存验证后的最终 HTTPS 地址与中央实例身份。Tailscale 检测只读取安装、登录和 DNS 状态，并把候选 HTTPS 地址填入文本框；不会建立或覆盖 Serve 规则，也不会保存现有设置。用户确认转发后再执行验证保存。可以暂时不配置网络，但远程 PC、Android 和正式 AI MCP 暂不可用。
6. 设备配对与 AI 配对都由管理 WebUI 按用户操作生成，不在每次启动时自动生成。设备使用现有 `LR1.` 邀请；AI 配对包由中央直接以浏览器下载方式生成，不依赖 PC 服务。
7. 再次运行时复用端口、身份、数据库和已验证外部地址。直接运行 `LifeLink Central Service.exe` 以及登录 Windows 后的自动启动保持静默；需要设置时从托盘打开 WebUI。

## 4. PC 客户端

用户运行 `pc-dashboard/start_central_client.bat`。脚本负责检查 Python、生成启动器、立即登记当前用户登录后自动启动并启动客户端。未配对时由客户端自己的设置页面显示配对码输入入口；已配对时复用 `%USERPROFILE%/LifeLink/client` 中的稳定身份和配置。未完成配对时，登录启动仍只进入客户端自己的配对引导，不在 BAT 中复制一套输入逻辑。

## 5. Android

- 不增加独立首次启动向导，继续由应用内配对入口完成连接。
- 连接失败时提示检查手机网络、Tailscale 或内网穿透，然后重试。
- 已配对设备重新连接时保持原设备身份。

## 6. AI 配对与定时读取

AI 不是首次安装的硬依赖。用户需要时，在中央管理 WebUI 验证 HTTPS 网络后生成 AI 配对包并交给支持 MCP 的 AI。所有正式 AI MCP（包括同机 AI）均通过该 HTTPS 地址访问中央；8092 管理页永不公开。AI 主机需要 Python 3.13 或 3.14，Linux/Docker 还需要私密持久状态目录。

如希望 AI 定期关注 Life Link，由用户在 AI 工具侧建立定时调用，定期检查更新标记并在需要时读取上下文。该定时制度属于 AI 工具的使用方式，Life Link 不擅自为外部 AI 创建任务。

## 7. 失败与恢复原则

- 每一步验证成功后才进入下一步；失败时保留已成功配置，允许修正后重试。
- 不以安装目录作为设备身份或数据库位置；所有安装副本共享 `%USERPROFILE%/LifeLink` 下的唯一数据。
- 不自动覆盖其他程序的端口或 Tailscale Serve 规则。
- 不把 Token、配对码或个人数据写进仓库、普通日志或开发文档。
- 已完成状态只跳过真正完成的步骤；启动器丢失、端口变化或服务不可用仍需重新检查。
